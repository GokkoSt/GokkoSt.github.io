¿Qué es CSS?

CSS (por sus siglas en inglés, Cascading Style Sheets, o Hojas de Estilo en Cascada) es un lenguaje de diseño gráfico que se utiliza para definir y crear el aspecto visual de un documento escrito en HTML o XML.?

¿Qué aprenderé en este curso?

Dominar el modelo de cajas, flexbox, CSS Grid, variables personalizadas, animación, diseño responsive y preprocesadores como Sass para crear sitios profesionales.

¿Qué es CSS GRID?

CSS Grid es un sistema de maquetación en dos dimensiones (filas y columnas) para la web que permite organizar y posicionar elementos de forma sencilla, flexible y adaptable.
